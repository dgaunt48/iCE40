# iCE40
In Progress iCE40 FPGA Projects.


## DaveFPGA
My custom iCE40 FPGA board with rp2354a and lots of level shifters I use when prototyping.

![DaveFPGA](DaveFPGA/Images/DaveFPGA.jpg?raw=true "Dave FPGA")

## VIA_6522
6522 VIA iCE40 FPGA Core is now running on a real Vic20 and passing all test on the diagnostic cartridge. It will boot to BASIC with the FPGA running the timers, performing the keyboard matrix scan and reading / writing serial data to the 1541.

![6522 Simulation](VIA_6522/Images/Sim_Port1.png?raw=true "Timer 1 Simulation")


## VIC_6560
Initial test to use the VIC hardware register values and memory dumps to create a VGA display.
