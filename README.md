# iCE40
Various iCE40 FPGA Projects.

## DaveFPGA
My custom iCE40 FPGA boards, see readme there for full description.

## iCE1k_VGA111
Display a 3bit VGA RGB test pattern on my iCE40hx1k based board.

## VIA_6522
6522 VIA iCE40 FPGA Core is now running on a real Vic20 and passing all tests on the diagnostic cartridge. It will boot to BASIC with the FPGA running the timers, performing the keyboard matrix scan and reading / writing serial data to the 1541.

![6522 Simulation](VIA_6522/Images/Sim_Port1.png?raw=true "Timer 1 Simulation")


## VIC_6560
